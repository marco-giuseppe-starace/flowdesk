## FlowDesk v0.5.1 - Release Notes

**Date:** 22 February 2026

### Fixed

- Dark mode readability improvements across the app.
- Fixed low-contrast text in cards and badges (including Environments view).
- Fixed icon visibility in action buttons in dark theme.
- Added and normalized missing theme tokens used by report/analyzer/sharepoint sections.
- Replaced fragile inline `--clr-*` usages with canonical theme variables.

### Technical

- App version bumped to `0.5.1`.
- No database schema changes.
- No API/IPC contract changes.
