## FlowDesk v0.6.3 - Release Notes

**Date:** 24 February 2026

### New

- Added **First-Run Onboarding** (3-step quick start):
  - Import demo workspace
  - Install starter template pack
  - GitHub growth CTA (star + community)

- Added **Starter Template Pack (1-click)** in Tasks > Template:
  - Power Apps Sprint
  - Bug Triage
  - Release Day
  - Retro Weekly
  - Client Delivery

- Added **Weekly Share Toolkit** in Dashboard:
  - `Share MD` for weekly snapshot markdown (clipboard-ready)
  - `Export PNG` for social/team sharing

### Improved

- Dashboard now includes a lightweight **Growth Kit** section with direct GitHub CTA.
- Onboarding is persisted via local storage to avoid repeating after first completion.

### Versioning

- App version bumped to `0.6.3`.
- New installer artifact: `FlowDesk Setup 0.6.3.exe` (Windows x64).

### Notes

- No database schema changes.
- Existing lint issues in `src/App.tsx` are pre-existing and unrelated to this release scope.
